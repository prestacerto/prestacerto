# Pacote do projeto PrestaCerto

Este pacote contém o código-fonte, rotas, componentes, testes, scripts, documentação e arquivos públicos do projeto.

## Como iniciar

```bash
npm ci
cp .env.example .env.local
# preencha as variáveis necessárias
npm run dev
```

Para validar antes de publicar:

```bash
npm run lint
npm run build
```

Credenciais, `.env`, `.git`, `node_modules`, `.next` e arquivos locais de build foram removidos deste pacote.
