## 🔥 PRÓXIMOS PASSOS (VOCÊ PRECISA FAZER):

### 1️⃣ Abrir Firebase Console
```
https://console.firebase.google.com
```

### 2️⃣ Criar Novo Projeto
- Clica **"+ Add project"**
- **Nome:** `prestacerto`
- Desativa Google Analytics
- Clica **"Create"** → aguarda 30s

### 3️⃣ Ativa Firestore
- Clica **"Firestore Database"** (esquerda)
- Clica **"Create Database"**
- Seleciona **"São Paulo"** (region)
- Seleciona **"Production mode"**
- Clica **"Create"** → aguarda 1 min

### 4️⃣ Ativa Authentication
- Clica **"Authentication"** (esquerda)
- Clica **"Get Started"**
- Ativa **"Email/Password"** → salva
- (Opcional) Ativa **"Google"** → salva

### 5️⃣ Copia Credenciais
- Clica ⚙️ **"Project Settings"** (rodapé)
- Scroll down → **"Your apps"** → **"</> Web"**
- Copia o `firebaseConfig` completo

### 6️⃣ Cola em `.env.local`
Abre: `/Users/cadusima/prestacerto/.env.local`

Substitui:
```env
NEXT_PUBLIC_FIREBASE_API_KEY=AIza...
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=prestacerto.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=prestacerto-xxx
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=prestacerto-xxx.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=123456789
NEXT_PUBLIC_FIREBASE_APP_ID=1:123456789:web:abc123
```
